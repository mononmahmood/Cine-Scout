# Cine Scout

Cine Scout is a modern web application designed to insert one sentence about what it does, e.g., discover and analyze film data. It is built with a focus on type safety, performance and seamless AI integration.

## Architecture

This repository is built on the [T3 Stack](https://create.t3.gg/), utilizing the following core technologies:

*   **Framework:** Next.js
*   **Language:** TypeScript
*   **Styling:** Tailwind CSS
*   **AI Integration:** Iceman Model

## Getting Started

To run this project locally, ensure you have Node.js installed, then execute the following commands:

```bash
# Install dependencies
npm install

# Set up your environment variables (copy the example file and add your Iceman model keys)
cp .env.example .env

# Start the development server
npm run dev
```
